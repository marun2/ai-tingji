# AI听记

均瑶健康的会议知识库：把钉钉 AI听记导出的 Excel 导进来，自动按部门整理，可以浏览、预览、搜索；后续加大模型提问、导出 Word、周报月报。

- 地址：https://apps.werdery.net/ai-tingji/ （在飞书工作台的企业中台里打开）
- 方案：[docs/方案.md](docs/方案.md)；开发交接：[CLAUDE.md](CLAUDE.md)

## 怎么用（管理员）
1. **管理 → 模型与分类**：填大模型的接口地址、模型、密钥，点“测试连接”
2. **管理 → 导入听记**：上传钉钉导出的 Excel，等进度条走完
3. **知识库 → 待确认**：核对系统拿不准的会，勾选后“确认所选”，或点开单独调整
4. 在**企业中台**里把应用的可见范围设为：董事局 + 指定的部门负责人

## 谁能看什么
| 谁 | 能看 |
|---|---|
| 管理员、董事局 | 全部文件夹，包括待确认 |
| 其他能打开的人（部门负责人） | 只有「研发市场销售」里已确认、非敏感的会 |
