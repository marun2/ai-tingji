# 界面风格（2026-11-24 用户选定：方案 C · 灰白）

设计画布（三种方向对比 + 黑白 + 最终灰白版）：https://claude.ai/artifact/HqyoUESFwYw8MGCf3xS6Le
用户的话：“纯黑太丑，logo 黑的也丑；要灰白、浅白、浅黑”。最终定第三排「方案 C · 灰白」，细节以后再慢慢调。

## 方向
知识工作台（类似 Obsidian）：左侧导航 + 文件夹，中间主内容（关系图谱 / 会议 / 回答），右侧详情或出处面板。
整体是“暖灰纸面 + 浮起的白色卡片”，靠灰度和淡阴影分层次，不用粗线、不用彩色。

## 配色
| 用途 | 色值 |
|---|---|
| 页面底色（暖灰） | `#f3f3f1` |
| 主卡片 | `#ffffff`，圆角 16，阴影 `0 0 0 1px rgba(0,0,0,.05), 0 1px 3px rgba(0,0,0,.04), 0 12px 32px -18px rgba(0,0,0,.12)` |
| 次级底（数字卡、图谱底） | `#f8f8f7` / `#fbfbfa`，描边 `#efeeeb` |

| 次要文字 | `#55555a` / `#6e6e73` |
| 提示文字 | `#8e8e93` / `#a1a1a6` |

| 图表灰阶 | `#3a3a3c` `#55555a` `#6e6e73` `#8e8e93` `#c7c7cc` `#d8d7d3` |

## 字体与排版
- Inter + Noto Sans SC（无则 PingFang SC），数字用 `tabular-nums`
- 页面标题 20px / 600 / 字距 -0.3px；数字卡数字 28px / 500 / 字距 -0.6px；正文 13.5–15px；提示 11.5–12px
- 圆角：卡片 16、控件 9–10、标签胶囊 99

## 组件要点
- Logo：浅灰渐变圆角方块（`#ffffff → #e8e7e3`，内描边），里面四根高低不一的“声波”竖条（`#8e8e93 / #55555a / #3a3a3c`）
- 导航选中项：白色小胶囊 + 极淡阴影；未选中为灰字
- 视图切换：分段按钮（灰底轨道，选中格为白色）
- 数字卡：浅底 + 迷你走势线（`#a1a1a6`）
- 图谱：点阵底；类别用**形状**区分——实心深灰圆=部门、空心圆=客户、圆角方块=产品、菱形=竞品、浅灰圆=话题；选中的连线加深
- 提问页：问题是右侧浅灰气泡；回答按正文排版，出处编号为灰色小标签；出处卡片横排，当前那张深色描边；输入框浮在底部（白底、圆角 16、阴影），发送为炭灰色上箭头按钮；右侧出处面板高亮被引用段落
