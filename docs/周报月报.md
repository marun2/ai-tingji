# 周报月报 · 设计说明

2026-11-25 重做。用户反馈“用户体验感受很差”。

## 旧版的问题
- 点“本周至今”会生成一份 0 场会议的空报告，还会留在列表里。
- 同一期的全公司版、研发市场销售版在列表里各占一行，看起来像重复。列表只有日期，看不出是第几周、有多少内容。
- 四个生成按钮点一下就调大模型，没有提示会花用量，也没有提示会覆盖已有报告。
- 阅读页：顶部的数字卡片很单薄，没有和上一期的对比；出处是一个个“会”字小圆点，打断阅读；正文很窄，右边一大片空白；没有目录，不能导出，也不方便转发。

## 现在的样子

**左侧列表**：一期一条，写“第 47 周”“2026年10月”，下面是日期和会议数。没看过的报告前面有个蓝点（只记在自己的浏览器里）。没有会议的空报告不列出。

**生成报告（只有管理员能用）**：点“生成报告”，右边列出最近 8 周（或 6 个月）的每一期：
- 每期显示有几场会、几场还没整理、是否已经生成过
- 没有会议的期不能生成
- 每个“生成”按钮上标着大约消耗多少 tokens（按会议数粗估）
- 已生成的显示“查看”和“重新生成”，重新生成会先弹窗确认“会覆盖原来的报告，并再消耗一次用量”
- 生成时左上角显示进度，完成后自动打开

自动生成照旧：每周一、每月 1 号早上 8 点后生成上一期；那一期没有会议就不生成。

**阅读页**：
- 标题“第 47 周经营周报”，右上角可以在全公司版 / 研发市场销售版之间切换（部门负责人只看得到研发市场销售版），还有“导出 Word”和“复制文字”（复制后可以直接粘贴到飞书）
- 数字卡片：会议、决议、风险问题、部门数（研发市场销售版显示经营数字个数），每个都和上一期比多了还是少了
- 这一期有会还没整理时，顶部会提示报告里没包含它们
- 正文里的出处改成小号数字角标（¹ ² ³），文末列出“引用的会议”，点角标或会议都能打开原会议。部门负责人只看得到自己有权限的会议出处
- 右侧栏：目录（点了跳到对应部分）、各部门会议数、热门话题、客户 / 平台 / 竞品 / 产品；宽屏时右侧栏跟着滚动
- 手机上列表在上、报告在下，右侧栏的内容排到正文后面

**导出 Word**：标题、期间、版本、对比数字、正文；出处改成 [1][2]，文末附引用的会议清单。

## 口径
- 报告内容由大模型根据抽取出的决议、风险、数字、客户产品话题写成，只依据资料、不写人名（`reports.PROMPT`）
- 对比数字（会议、决议、风险、部门）是打开报告时现算的，不调大模型；上一期：周报是前一周的同样几天，月报是上个月
- 研发市场销售版只用研发市场销售里已确认、非敏感的会
